1. À QUI S'ADRESSE CE GUIDE
--------------------------------------------------------------------------------

Ce guide est destiné :
- au personnel administratif ;
- aux responsables de formation et responsables pédagogiques ;
- aux formateurs ;
- aux maîtres de stage ;
- aux RH et auditeurs ;
- aux administrateurs ;
- aux stagiaires.

Chaque utilisateur ne voit que les pages autorisées par son rôle. Si une page
citée dans ce guide n'apparaît pas dans votre menu, elle n'est probablement pas
autorisée pour votre compte. Contactez l'administrateur si vous pensez qu'il
s'agit d'une erreur.

L'application sert à :
- gérer les dossiers des stagiaires ;
- gérer les formations, modules, promotions et séances ;
- inscrire les candidats et confirmer les réservations ;
- faire le suivi des présences ;
- organiser les évaluations, QCM et travaux pratiques ;
- suivre les compétences et le comportement ;
- produire les évaluations finales, bulletins et documents ;
- permettre au stagiaire de consulter son espace personnel.

2. SE CONNECTER ET SE DÉCONNECTER
--------------------------------------------------------------------------------

2.1 Adresses utiles

Accueil public : /
Connexion : /login
Réservation publique : /reservation
Diagnostic technique Forge : /forge
Espace du personnel : /app
Espace du stagiaire : /app/mon-espace

2.2 Se connecter

1. Ouvrir l'application.
2. Cliquer sur « Se connecter » ou aller sur /login.
3. Saisir l'adresse email du compte.
4. Saisir le mot de passe.
5. Cliquer sur « Se connecter ».
6. L'application ouvre la page correspondant à votre rôle.

Pour un stagiaire, l'application ouvre automatiquement /app/mon-espace.
Pour le personnel, elle ouvre /app.

2.3 Se déconnecter

1. Cliquer sur votre nom ou votre avatar en haut à droite.
2. Cliquer sur « Se déconnecter ».

Déconnectez-vous toujours sur un poste partagé.

2.4 Si la connexion échoue

Vérifier :
- l'orthographe de l'email ;
- le mot de passe ;
- que le compte a bien été créé ;
- que le clavier n'est pas en majuscules ;
- que le compte n'a pas été supprimé.

L'application ne propose pas de lien « Mot de passe oublié ». Un administrateur
doit intervenir. Voir la section 66.

2.5 Première connexion d'un stagiaire

Un stagiaire reçoit généralement son compte après confirmation d'une réservation.
L'administration lui communique :
- son adresse email ;
- un mot de passe temporaire de la forme SB-XXXX####.

Le mot de passe temporaire est affiché au moment de la confirmation. Il faut le
copier ou le noter avant de fermer la fenêtre.

5. LES ACTIONS COMMUNES À PRESQUE TOUTES LES PAGES
--------------------------------------------------------------------------------

5.1 Ouvrir une page

Utiliser le menu de gauche, ou saisir directement l'adresse dans le navigateur
si vous connaissez le chemin.

5.2 Rechercher dans une liste

La plupart des pages proposent un champ « Rechercher... ».
- La recherche porte sur les lignes déjà chargées.
- Elle ne fait pas une recherche dans toute la base.
- Pour une recherche transversale, utiliser « Recherche globale ».

5.3 Créer un enregistrement

Le fonctionnement standard est :
1. Ouvrir la page.
2. Cliquer sur le bouton de création, par exemple « Nouveau stagiaire »,
   « Nouvelle inscription » ou « Nouvelle évaluation ».
3. Remplir le formulaire.
4. Les champs marqués d'un astérisque ou signalés « requis » sont obligatoires.
5. Cliquer sur « Créer ».
6. La liste se met à jour.

Sur certaines pages, le bouton porte un nom différent :
- « Créer la question »
- « Créer le compte »
- « Créer le plan »
- « Enregistrer l'évaluation »
- « Déposer »

5.4 Modifier un enregistrement

1. Repérer la ligne.
2. Cliquer sur l'icône crayon ou sur « Modifier ».
3. Modifier les champs.
4. Cliquer sur « Enregistrer ».

5.5 Supprimer un enregistrement

1. Repérer la ligne.
2. Cliquer sur l'icône corbeille ou sur « Supprimer ».
3. Confirmer dans la fenêtre de sécurité.

ATTENTION : la suppression est directe. Il n'y a pas de corbeille et pas de
bouton « Annuler ». Pour conserver une donnée, préférez un statut « Archivé »
ou « Inactif » quand il existe.

5.6 Annuler une saisie

Dans une fenêtre de création ou de modification, cliquer sur « Annuler ».
Les données saisies dans la fenêtre sont perdues.

5.7 Rafraîchir les données

- Recharger la page avec le navigateur.
- Ou utiliser le bouton « Actualiser » quand il existe.

Certaines données de référence sont mises en cache pendant environ une minute.
Un élément nouvellement créé peut donc mettre un peu de temps à apparaître dans
un menu déroulant.

5.8 Fermer une fenêtre

Cliquer sur « Annuler », sur la croix, ou en dehors de la fenêtre.

5.9 Exporter et imprimer

- Export CSV : page Rapports & statistiques.
- Impression : boutons « Imprimer » dans Bulletins et Documents.
- Pour obtenir un PDF : cliquer sur « Imprimer », puis choisir
  « Enregistrer au format PDF » dans la fenêtre d'impression du navigateur.

5.10 Limite des listes

Les listes affichent au maximum 200 lignes par table. Il n'y a pas de pagination.
Si une donnée récente n'apparaît pas :
- recharger la page ;
- utiliser la recherche de la page ;
- vérifier que la donnée a bien été enregistrée ;
- contacter l'administrateur si le volume est important.

6. TABLEAU DE BORD
--------------------------------------------------------------------------------

Page : /app
Menu : Vue d'ensemble > Tableau de bord

6.1 À quoi sert la page

Le tableau de bord donne une vue rapide :
- nombre de stagiaires actifs ;
- moyenne globale ;
- taux de présence ;
- taux de réussite ;
- alertes ;
- stagiaires à risque ;
- derniers stagiaires ;
- prochaines séances ;
- prochaines évaluations ;
- accès rapides.

6.2 Comment l'utiliser

1. Ouvrir /app.
2. Lire les cartes du haut.
3. Consulter le bloc « Stagiaires à risque ».
4. Utiliser les accès rapides pour ouvrir une page fréquente.
5. Cliquer sur un stagiaire pour ouvrir son dossier.

6.3 À savoir

- Les statistiques sont calculées sur les données chargées, avec un plafond de
  200 lignes par table. Elles peuvent donc être partielles sur de gros volumes.
- Le tableau de bord ne permet pas de modifier directement les données.
- Un stagiaire est considéré « à risque » si sa moyenne est inférieure à 10/20
  ou si son taux de présence est inférieur à 80 %.

7. STAGIAIRES
--------------------------------------------------------------------------------

Page : /app/stagiaires
Menu : Dossiers > Stagiaires

7.1 À quoi sert la page

Elle sert à :
- créer un dossier stagiaire ;
- modifier ses informations ;
- changer son statut ;
- supprimer un dossier ;
- ouvrir le dossier complet.

7.2 Créer un stagiaire

1. Ouvrir /app/stagiaires.
2. Cliquer sur « Nouveau stagiaire ».
3. Remplir les champs.

Champs obligatoires :
- Matricule ;
- Prénom ;
- Nom ;
- Statut.

Champs utiles :
- Postnom ;
- Sexe ;
- Date de naissance ;
- Lieu de naissance ;
- Email ;
- Téléphone ;
- Adresse ;
- Établissement d'origine ;
- Niveau d'études ;
- Diplôme ;
- Domaine ;
- Spécialité ;
- Contact d'urgence ;
- Téléphone d'urgence.

4. Choisir le statut :
   - Candidat ;
   - Admis ;
   - Actif ;
   - Terminé ;
   - Archivé.
5. Cliquer sur « Créer ».

Exemple de matricule : SB-2026-001.

À SAVOIR : le matricule et l'email doivent être uniques. L'application ne fait
pas de vérification préalable, mais un doublon est refusé à l'enregistrement.
Utilisez un matricule et un email différents pour chaque stagiaire.

7.3 Modifier un stagiaire

1. Repérer la ligne.
2. Cliquer sur le crayon.
3. Modifier les informations.
4. Cliquer sur « Enregistrer ».

7.4 Ouvrir le dossier complet

1. Repérer la ligne.
2. Cliquer sur l'icône dossier, ou sur « Voir le dossier complet ».
3. La page /app/stagiaires/:id s'ouvre.

Le dossier contient :
- identité et coordonnées ;
- moyenne des notes ;
- taux de présence ;
- compétences acquises ;
- moyenne finale ;
- inscriptions ;
- onglets Aperçu, Notes, Présences, Compétences et Suivi pédagogique ;
- objectifs, journal, bulletins, observations et plans.

7.5 Consulter les présences d'un stagiaire

1. Ouvrir /app/stagiaires.
2. Ouvrir le dossier du stagiaire.
3. Cliquer sur l'onglet « Présences ».
4. Lire les séances, les statuts et les justifications.

Autres endroits pour voir les présences :
- /app/progression après avoir choisi le stagiaire ;
- /app/rapports pour les statistiques globales ;
- /app/mon-espace/presences pour le stagiaire lui-même.

7.6 Changer le statut d'un stagiaire

1. Modifier le stagiaire.
2. Changer le champ « Statut ».
3. Enregistrer.

Signification des statuts :
- Candidat : dossier créé, pas encore admis.
- Admis : candidature acceptée, formation pas encore commencée.
- Actif : stagiaire en formation.
- Terminé : formation achevée.
- Archivé : dossier conservé mais sorti des listes actives.

7.7 Supprimer un stagiaire

1. Cliquer sur la corbeille.
2. Confirmer.

ATTENTION : la suppression ne supprime pas automatiquement les notes, présences,
inscriptions et autres données liées. Elle peut rendre des données orphelines.
Préférez le statut « Archivé ».

7.8 À savoir

- Un dossier archivé ne peut pas être utilisé pour confirmer une réservation.
- Le dossier détail est en lecture seule.
- Les notes, présences et observations y sont visibles pour tout rôle ayant
  accès à la page Stagiaires, même si ce rôle n'a pas les pages Notes ou
  Observations.

8. INSCRIPTIONS
--------------------------------------------------------------------------------

Page : /app/inscriptions
Menu : Dossiers > Inscriptions

8.1 À quoi sert la page

Elle relie un stagiaire à une formation et, si besoin, à une promotion.

8.2 Inscrire un stagiaire

1. Ouvrir /app/inscriptions.
2. Cliquer sur « Nouvelle inscription ».
3. Choisir le stagiaire.
4. Choisir la formation.
5. Choisir la promotion si nécessaire.
6. Renseigner la date de début et la date de fin.
7. Choisir le statut :
   - En attente ;
   - Validée ;
   - Annulée ;
   - Terminée.
8. Cliquer sur « Créer ».

Pour une inscription directe, choisir directement « Validée » si le dossier est
complet.

8.3 Modifier une inscription

1. Cliquer sur le crayon.
2. Modifier les dates, la promotion ou le statut.
3. Enregistrer.

8.4 Changer le statut

- En attente : demande non finalisée.
- Validée : inscription acceptée.
- Annulée : inscription abandonnée.
- Terminée : parcours achevé.

Les inscriptions En attente, Validée et Terminée comptent dans les places
occupées pour les réservations.

8.5 À savoir

- L'application ne bloque pas les doublons. Vérifiez qu'il n'existe pas déjà une
  inscription pour le même stagiaire, la même formation et la même promotion.
- La capacité de la promotion n'est pas contrôlée lors d'une inscription
  manuelle.
- Une inscription ne crée pas de compte utilisateur.
- Une inscription ne crée pas d'affectation.

Elle indique :

5. Saisir le service ou département.
6. Choisir le formateur référent.

9.4 À savoir

- Une affectation ne crée pas d'inscription.
- L'application ne bloque pas les doublons.
- Ne confondez pas :
  - le formateur du module, choisi dans /app/modules ;
  - le formateur de la séance, choisi dans /app/seances ;
  - le formateur référent, choisi dans /app/affectations.
  Ces trois champs sont indépendants.

10. RÉSERVATIONS
--------------------------------------------------------------------------------

Pages :
- Formulaire public : /reservation
- Gestion du personnel : /app/reservations

Menu : Dossiers > Réservations

10.1 Principe

Un candidat réserve une place en ligne. La réservation est d'abord « En attente ».
L'administration vérifie la demande, puis confirme. La confirmation crée ou
réutilise le dossier stagiaire, l'inscription et le compte du stagiaire.

10.2 Le candidat réserve une place

1. Ouvrir /reservation.
2. Choisir la formation.
3. Choisir la promotion ouverte.
4. Saisir :
   - Prénom (obligatoire) ;
   - Nom (obligatoire) ;
   - Postnom (facultatif) ;
   - Sexe (facultatif) ;
   - Date de naissance (facultative) ;
   - Téléphone (obligatoire) ;
   - Email (obligatoire).
5. Cliquer sur « Réserver ma place ».
6. Noter la référence affichée, par exemple RES-2026-ABC123.
7. Se présenter à l'administration avec la référence et une pièce d'identité.

À SAVOIR :
- Aucun paiement n'est effectué en ligne.
- La réservation ne crée pas encore de compte.
- La réservation reste en attente jusqu'à la confirmation.
- Les places libres tiennent compte des inscriptions et des autres réservations
  en attente.
- Le système refuse une réservation si l'email possède déjà un dossier ou un
  compte.
- Le système refuse une deuxième réservation pour la même formation et la même
  promotion avec le même email.

10.3 L'administration consulte les réservations

1. Ouvrir /app/reservations.
2. Lire les cartes de disponibilité :
   - « Illimité » ;
   - « Complet » ;
   - « N places libres ».
3. Utiliser le champ de recherche pour retrouver une référence, un nom ou un
   email.
4. Filtrer par statut :
   - Tous les statuts ;
   - En attente ;
   - Confirmée ;
   - Annulée.
5. Cliquer sur « Voir le détail » pour lire la demande.

10.4 Confirmer une réservation

1. Vérifier que la réservation est « En attente ».
2. Cliquer sur « Confirmer ».
3. Lire le récapitulatif.
4. Vérifier la disponibilité.
5. Confirmer l'opération.
6. Lire la fenêtre « Réservation confirmée ».
7. Copier ou noter :
   - le matricule créé ou réutilisé ;
   - le type de compte ;
   - le mot de passe temporaire éventuel ;
   - les liens vers le dossier, l'inscription et le compte.
8. Communiquer les identifiants au candidat.

Ce que le système fait :
- contrôle la capacité ;
- réutilise un dossier existant par email s'il n'est pas archivé ;
- crée un dossier avec le statut « Admis » si nécessaire ;
- réutilise une inscription existante non annulée ;
- crée une inscription « Validée » si nécessaire ;
- réutilise un compte existant si le rôle et le dossier correspondent ;
- crée un compte stagiaire avec un mot de passe temporaire si nécessaire ;
- passe la réservation à « Confirmée ».

Si une étape échoue, le système tente de supprimer les éléments créés.

10.5 Annuler une réservation

1. Repérer une réservation « En attente ».
2. Cliquer sur « Annuler ».
3. Confirmer.

Une réservation confirmée ne peut plus être annulée depuis cette page. Une
réservation annulée libère la place en attente.

10.6 Erreurs fréquentes

« Cette promotion est complète »
- La capacité est atteinte en tenant compte des inscriptions actives et des
  réservations en attente.
- Annuler une réservation en attente ou libérer une inscription.

« Une réservation existe déjà pour cette formation et cette promotion »
- Même email, même formation, même promotion, avec une réservation en attente ou
  confirmée.

« Un dossier ou un compte existe déjà avec cet email »
- Utiliser la fiche stagiaire existante.
- Ne pas refaire une réservation publique.

« Le dossier stagiaire associé à cet email est archivé »
- Restaurer le dossier dans /app/archivage ou traiter le cas manuellement.

« La table reservations n'existe pas encore »
- L'administrateur doit installer la table des réservations. Contacter le
  support technique.

10.7 À savoir

- La page /app/reservations ne permet pas de créer une réservation manuellement.
- Pour inscrire un candidat sans réservation, utiliser /app/stagiaires puis
  /app/inscriptions.
- La capacité est contrôlée pour les réservations, pas pour les inscriptions
  manuelles.
- La confirmation peut réutiliser un dossier ou un compte existant.
- Le mot de passe temporaire n'est pas toujours réaffiché après fermeture.

18. QCM
--------------------------------------------------------------------------------

Page : /app/qcm
Menu : Évaluations > QCM

18.1 À quoi sert la page

- construire un QCM ;
- ajouter des questions ;
- lancer une passation ;
- consulter les résultats.

18.2 Avant de commencer

Il faut d'abord créer une évaluation dans /app/evaluations :
- type « QCM » ;
- cocher « Cette évaluation est un QCM » ;
- choisir une formation et un module ;
- choisir une date ;
- choisir un statut autre que brouillon pour une utilisation par les stagiaires.

18.3 Ajouter des questions

1. Ouvrir /app/qcm.
2. Choisir le questionnaire.
3. Rester sur l'onglet « Questions ».
4. Cliquer sur « Ajouter une question ».
5. Renseigner :
   - Question (obligatoire) ;
   - Type (obligatoire) ;
   - Points (minimum 0,5) ;
   - Ordre ;
   - Options ;
   - Réponse correcte (obligatoire).
6. Cliquer sur « Créer la question ».

18.4 Types de questions

- Choix unique ;
- Choix multiple ;
- Vrai / Faux ;
- Réponse courte ;
- Association.

18.5 Saisie des options et des réponses

Options :
- une option par ligne ;
- pour Vrai/Faux, laisser vide ou utiliser Vrai et Faux.

Réponse correcte :
- saisir exactement le texte de la bonne option ;
- pour un choix multiple, séparer les réponses par des virgules ;
- la comparaison ignore les majuscules et les espaces autour.

Exemple choix multiple :
Paris, Lyon

18.6 Points et correction

- La note maximale du QCM est la somme des points des questions.
- Une bonne réponse rapporte tous les points de la question.
- Une question sans réponse rapporte 0.
- Un choix multiple doit correspondre exactement : pas de demi-point.
- Le QCM est réussi à partir de 50 %.
- Le type « Association » n'a pas de correction spécifique et se comporte comme
  une réponse simple. Évitez ce type pour un vrai exercice d'association.

18.7 Lancer une passation

1. Choisir le questionnaire.
2. Cliquer sur « Lancer une passation ».
3. Choisir le stagiaire.
4. Répondre aux questions.
5. Cliquer sur « Soumettre le QCM ».
6. Confirmer.

La correction est automatique et une tentative est enregistrée.

18.8 Consulter les résultats

1. Ouvrir /app/qcm.
2. Choisir le questionnaire.
3. Cliquer sur l'onglet « Passations ».
4. Lire :
   - le stagiaire ;
   - la date ;
   - le score ;
   - le pourcentage ;
   - le statut ;
   - le résultat réussi ou échoué.
5. La moyenne affichée est une moyenne de points, pas une moyenne sur 20.

18.9 Ce que le QCM ne fait pas

- Il ne crée pas de note dans /app/notes.
- Il ne crée pas de bulletin.
- Il n'envoie pas de notification.
- Il ne limite pas le nombre de tentatives.
- Il ne contrôle pas de fenêtre de disponibilité.
- Il n'empêche pas un stagiaire de repasser le QCM.

18.10 Pour intégrer le QCM dans les résultats

Deux possibilités :
1. Saisir manuellement une note dans /app/notes.
2. Laisser le QCM alimenter le critère QCM de l'évaluation finale.

L'évaluation finale reprend automatiquement les tentatives corrigées.

18.11 À savoir

- Les réponses correctes sont présentes dans le navigateur.
- Pour un examen sensible, faites passer le QCM sous surveillance.
- La page charge au maximum 200 questions et 200 tentatives.
- Le numéro de tentative dépend des tentatives déjà chargées.

30. ÉVALUATION FINALE
--------------------------------------------------------------------------------

Page : /app/evaluation-finale
Menu : Résultats > Évaluation finale

30.1 À quoi sert la page

Consolider les résultats et formaliser la décision finale.

30.2 Avant de commencer

Vérifier que les données existent :
- notes ;
- présences ;
- tentatives QCM corrigées ;
- notes de TP ;
- projet final ;
- implication ;
- comportement.

30.3 Calculer une évaluation finale

1. Ouvrir /app/evaluation-finale.
2. Choisir le stagiaire.
3. Lire les cartes :
   - Modules /20 ;
   - QCM /20 ;
   - TP /20 ;
   - Projet final /20.
4. Vérifier le taux de présence, l'implication et le comportement.
5. Ajuster les coefficients si nécessaire.
6. Lire la moyenne finale pondérée.
7. Choisir la décision finale :
   - En attente ;
   - Validé ;
   - Non validé.
8. Saisir une appréciation générale.
9. Cliquer sur :
   - « Enregistrer » pour créer une évaluation finale ;
   - ou « Valider et publier » pour créer une évaluation finale publiée.
10. Confirmer.

30.4 Coefficients par défaut

Critère             Base              Coefficient
Modules             /20               40
QCM                 /20               10
TP                  /20               15
Projet final        /20               20
Implication         /5 converti /20   5
Comportement        /5 converti /20   5
Présence            % converti /20    5

La moyenne finale est la somme des critères pondérés divisée par la somme des
coefficients. Les coefficients n'ont pas besoin de totaliser 100.

30.5 Rôle de la décision

La décision est choisie manuellement. Le seuil de 10/20 ne décide pas
automatiquement si le stagiaire est validé ou non.

30.6 IMPORTANT : chaque enregistrement crée une ligne

« Enregistrer » et « Valider et publier » créent tous les deux une nouvelle
évaluation finale. L'ancienne reste dans l'historique. La plus récente est celle
qui est utilisée par les bulletins et l'espace stagiaire.

Conseil : vérifiez toutes les données avant d'enregistrer. Si vous devez
corriger, enregistrez une nouvelle version et vérifiez que c'est bien la
dernière.

30.7 Visibilité côté stagiaire

L'espace stagiaire affiche la dernière évaluation finale disponible, même si vous
avez utilisé « Enregistrer » sans publier. Ne créez pas une évaluation finale
provisoire si vous ne voulez pas qu'elle soit visible.

Le bulletin, lui, doit être généré et publié séparément.

30.8 Ce que l'évaluation finale ne fait pas

- Elle ne crée pas de bulletin.
- Elle ne crée pas de document.
- Elle n'envoie pas de notification.
- Elle n'applique pas les coefficients des notes ni des modules.
- Elle n'empêche pas les doublons.

56. OUVRIR UNE NOUVELLE FORMATION
--------------------------------------------------------------------------------

Objectif : préparer une formation complète avant les inscriptions.

Étape 1 - Créer la formation
1. /app/formations > « Nouvelle formation ».
2. Renseigner le nom, le domaine, le niveau, la durée et le statut « Active ».
3. Créer.

Étape 2 - Créer les modules
1. /app/modules > « Nouveau module ».
2. Choisir la formation.
3. Renseigner le nom, le coefficient, les heures et le seuil.
4. Créer chaque module.

Étape 3 - Créer une promotion
1. /app/promotions > « Nouvelle promotion ».
2. Choisir la formation.
3. Saisir le code, les dates et la capacité.
4. Statut « Planifiée » ou « Active ».
5. Créer.

Étape 4 - Créer les séances
1. /app/seances > « Nouvelle séance ».
2. Choisir le module et la promotion.
3. Renseigner la date, l'heure, la salle et le formateur.
4. Créer.

Étape 5 - Vérifier
1. La formation est active.
2. La promotion est ouverte.
3. Les modules sont actifs.
4. Les séances sont planifiées.
5. Les formateurs sont affectés.

Étape 6 - Inscrire les stagiaires
- Via /app/inscriptions pour une inscription manuelle.
- Via /app/reservations pour les demandes en ligne.

--------------------------------------------------------------------------------
57. INSCRIRE UN CANDIDAT MANUELLEMENT
--------------------------------------------------------------------------------

Utiliser ce circuit quand le candidat ne passe pas par le formulaire public.

1. Créer le dossier dans /app/stagiaires.
2. Créer l'inscription dans /app/inscriptions avec le statut « Validée ».
3. Créer l'affectation dans /app/affectations.
4. Créer le compte dans /app/utilisateurs :
   - rôle Stagiaire ;
   - dossier stagiaire lié ;
   - mot de passe ;
   - statut Actif.
5. Communiquer les identifiants au stagiaire.
6. Vérifier que le stagiaire voit son espace.

Si le candidat possède déjà un dossier, ne le recréez pas : utilisez le dossier
existant.

--------------------------------------------------------------------------------
58. TRAITER UNE RÉSERVATION DE BOUT EN BOUT
--------------------------------------------------------------------------------

1. Le candidat remplit /reservation.
2. Il note sa référence.
3. L'administration ouvre /app/reservations.
4. Elle vérifie les places disponibles.
5. Elle ouvre le détail.
6. Elle confirme.
7. Elle copie le mot de passe temporaire.
8. Elle communique les identifiants.
9. Le stagiaire se connecte.
10. Il complète son profil.
11. L'administration vérifie l'inscription et l'affectation.
12. Le stagiaire apparaît dans les listes de présence.

Si la réservation est annulée, aucune inscription n'est créée.

--------------------------------------------------------------------------------
59. FAIRE L'APPEL DE BOUT EN BOUT
--------------------------------------------------------------------------------

1. Vérifier que la séance existe dans /app/seances.
2. Vérifier que la promotion de la séance est correcte.
3. Ouvrir /app/presences.
4. Choisir la séance.
5. Cliquer sur « Tous présents » si la majorité est présente.
6. Corriger les absents, retards et sorties.
7. Ajouter les justifications.
8. Enregistrer la feuille.
9. Vérifier le taux affiché.
10. Consulter le dossier d'un stagiaire si nécessaire.

Si le message d'enregistrement partiel apparaît :
- noter les stagiaires non enregistrés ;
- recharger la page ;
- recommencer l'enregistrement ;
- vérifier les doublons.

--------------------------------------------------------------------------------
60. ORGANISER UN QCM DE BOUT EN BOUT
--------------------------------------------------------------------------------

Étape 1 - Créer l'évaluation
1. /app/evaluations > « Nouvelle évaluation ».
2. Choisir le type « QCM ».
3. Cocher « Cette évaluation est un QCM ».
4. Choisir la formation, le module, la date et le statut.
5. Créer.

Étape 2 - Ajouter les questions
1. /app/qcm.
2. Choisir le QCM.
3. « Ajouter une question ».
4. Saisir la question, le type, les points et l'ordre.
5. Saisir les options, une par ligne.
6. Saisir la réponse correcte.
7. Créer la question.
8. Répéter.

Étape 3 - Vérifier
1. Relire chaque question.
2. Vérifier les réponses correctes.
3. Vérifier les points.
4. Faire une passation test.
5. Lire le résultat.

Étape 4 - Faire passer
1. « Lancer une passation ».
2. Choisir le stagiaire.
3. Le stagiaire répond.
4. Soumettre.
5. Vérifier la tentative dans l'onglet Passations.

Étape 5 - Exploiter le résultat
- Le score est enregistré dans l'onglet « Passations ».
- Aucune note n'est créée.
- Pour une note, la saisir dans /app/notes.
- Pour la moyenne finale, le critère QCM est repris automatiquement.

Étape 6 - Sécuriser
- Surveiller la passation.
- Éviter de laisser un stagiaire seul avec les réponses.
- Ne pas utiliser le QCM comme examen à fort enjeu sans contrôle.

Réglages à éviter :
- options vides pour un choix unique ;
- réponse correcte ne correspondant à aucune option ;
- plusieurs réponses sans virgule ;
- type « Association » sans tests ;
- points à zéro ;
- QCM non coché « Cette évaluation est un QCM ».

--------------------------------------------------------------------------------
61. ORGANISER UN TRAVAIL PRATIQUE DE BOUT EN BOUT
--------------------------------------------------------------------------------

1. Créer le TP dans /app/travaux.
2. Renseigner le module, l'échéance, les consignes et les livrables.
3. Passer le statut à « Publié ».
4. Le stagiaire dépose un lien depuis /app/mon-espace/travaux.
5. Ouvrir l'onglet « Soumissions & corrections ».
6. Consulter le dépôt.
7. Saisir la note sur 20.
8. Rédiger le feedback.
9. Choisir le statut de la soumission.
10. Enregistrer.
11. Saisir éventuellement une note dans /app/notes si le TP doit compter dans
    la moyenne de module.
12. Le critère TP de l'évaluation finale reprend automatiquement les notes.

65. RÔLES ET ACCÈS
--------------------------------------------------------------------------------

65.1 Administrateur
Accès complet. Gère les comptes, les paramètres, les archives et toutes les
données. Il est le seul à pouvoir créer des comptes et modifier les paramètres.

65.2 Direction
Accès large :
- dossiers ;
- pédagogie ;
- évaluations ;
- suivi ;
- résultats ;
- rapports ;
- archivage.
Pas d'accès aux utilisateurs, au journal d'audit ni aux paramètres.

65.3 Responsable de formation
Accès proche de la direction, sans archivage, sans utilisateurs, sans audit et
sans paramètres. Il possède les permissions de validation et de publication.

65.4 Responsable pédagogique
Accès proche du responsable de formation. Il possède la validation des notes,
mais pas la permission de publication des bulletins.

65.5 Formateur
Accès aux stagiaires, formations, promotions, séances, présences, évaluations,
notes, QCM, TP, compétences, implication, comportement, observations,
progression, plans, journal, objectifs et projet final.
Pas d'accès aux inscriptions, réservations, affectations, évaluations
intermédiaires, évaluation finale, bulletins, documents, rapports, archivage,
utilisateurs, audit ou paramètres.

65.6 Maître de stage
Accès aux stagiaires, objectifs, journal, compétences, implication, comportement,
observations, projet final, notifications et recherche.

65.7 Service administratif
Accès aux stagiaires, inscriptions, réservations, affectations, documents,
notifications, recherche et archivage.

65.8 RH
Accès aux stagiaires, rapports, documents, notifications et recherche.

65.9 Auditeur
Accès aux stagiaires, rapports, audit, notifications et recherche.

65.10 Stagiaire
Accès uniquement à son espace personnel et à ses 22 pages.

65.11 Point important sur le dossier stagiaire

Tout rôle qui possède la page Stagiaires peut ouvrir le dossier détail et voir :
- les notes ;
- les présences ;
- les compétences ;
- les observations ;
- le suivi.

Cela s'applique aussi aux rôles qui n'ont pas les pages Notes ou Observations.
Ne considérez donc pas le dossier détail comme un espace réservé à l'équipe
pédagogique.

65.12 Changement de rôle

Un changement de rôle n'est pas appliqué en temps réel. L'utilisateur doit se
déconnecter puis se reconnecter.

66. PROBLÈMES FRÉQUENTS
--------------------------------------------------------------------------------

66.1 « Je ne vois pas une page dans le menu »

Cause : le rôle n'a pas la permission.
Solution :
1. Vérifier votre rôle avec l'administrateur.
2. Faire changer le rôle si nécessaire.
3. Se déconnecter puis se reconnecter.

66.2 « Accès refusé »

Cause : vous avez ouvert une adresse non autorisée.
Solution : revenir au tableau de bord ou demander l'accès.

66.3 « Aucun stagiaire éligible » dans Présences

Causes :
- la séance n'a pas de promotion ;
- aucun stagiaire n'est inscrit à cette promotion ;
- l'inscription n'existe pas.
Solution :
1. Vérifier la promotion de la séance.
2. Vérifier les inscriptions.
3. Corriger la séance ou inscrire les stagiaires.

66.4 « Aucun stagiaire éligible » dans Notes

Causes :
- l'évaluation est liée à une formation sans inscrits ;
- les inscriptions manquent.
Solution :
1. Vérifier la formation de l'évaluation.
2. Vérifier les inscriptions.
3. Si l'évaluation n'a pas de formation, tous les stagiaires sont proposés.

66.5 Une note n'apparaît pas chez le stagiaire

Cause : la note n'est pas au statut « Publiée ».
Solution :
1. Vérifier le statut dans /app/notes.
2. Demander à l'administrateur de publier la note dans Forge.
3. Recharger l'espace stagiaire.

66.6 Le QCM n'apparaît pas dans /app/qcm

Causes :
- l'évaluation n'est pas cochée « Cette évaluation est un QCM » ;
- l'évaluation n'existe pas.
Solution : modifier l'évaluation et cocher la case.

66.7 Le QCM n'apparaît pas chez le stagiaire

Causes :
- l'évaluation est en brouillon ;
- l'évaluation est archivée ;
- la formation ne correspond pas.
Solution : changer le statut et vérifier la formation.

66.8 Les boutons de bulletin sont grisés

Cause : aucune évaluation finale n'existe pour le stagiaire.
Solution : aller dans /app/evaluation-finale et enregistrer une évaluation.

66.9 Le bulletin ne se met pas à jour

Cause : le contenu du bulletin est figé.
Solution : générer un nouveau bulletin après avoir corrigé les notes.

66.10 Une réservation ne peut pas être confirmée

Causes possibles :
- promotion complète ;
- email déjà utilisé ;
- dossier archivé ;
- compte existant incompatible ;
- table reservations absente.
Solution : lire le message, corriger la situation, puis réessayer.

66.11 La page Réservations affiche une erreur de table

Cause : la table reservations n'est pas installée.
Solution : contacter l'administrateur technique.

66.12 Le mot de passe est perdu

L'application ne permet pas de le réinitialiser.
Solution : contacter l'administrateur. Il peut recréer le compte ou intervenir
dans Forge.

66.13 Un email, un SMS ou un push n'est pas parti

Cause : seules les notifications internes sont enregistrées.
Solution : utiliser un autre canal ou contacter l'administrateur.

66.14 Un fichier ne s'ouvre pas

Cause : le champ contient une URL externe, pas un fichier hébergé.
Solution : vérifier le lien, les droits de partage et le réseau.

66.15 L'impression est vide

Vérifier :
- qu'un stagiaire est sélectionné ;
- qu'un bulletin ou document est affiché ;
- que la zone d'impression est visible ;
- que le navigateur n'empêche pas l'impression.

66.16 Les données ne se mettent pas à jour

- Recharger la page.
- Attendre une minute pour les listes de référence.
- Vérifier que l'enregistrement a bien été confirmé.

66.17 Une liste s'arrête à 200 lignes

C'est une limite de l'application. Utiliser la recherche ou contacter
l'administrateur pour les gros volumes.

66.18 Une évaluation finale ou un bulletin est en double

C'est possible : chaque enregistrement crée une nouvelle ligne. La plus récente
est utilisée. Supprimer les anciennes si nécessaire.

66.19 Un stagiaire n'apparaît pas dans une promotion

Vérifier :
- son inscription ;
- la formation ;
- la promotion ;
- le statut de l'inscription.

66.20 Le thème ne change pas

Cliquer sur l'icône lune/soleil en haut à droite, ou utiliser
/app/mon-espace/parametres pour un stagiaire.

--------------------------------------------------------------------------------
67. LIMITES À CONNAÎTRE
--------------------------------------------------------------------------------

67.1 Listes
- 200 lignes maximum par liste.
- Pas de pagination.
- Les statistiques peuvent être partielles.

67.2 Notes
- Coefficients non appliqués.
- Coefficients de modules non appliqués.
- Pas de bouton Publier dans Notes.
- Les notes validées ne sont pas visibles par le stagiaire sans publication.
- Les notes non publiées sont prises en compte dans les calculs du personnel.

67.3 Résultats
- Aucune décision automatique.
- Aucun bulletin automatique.
- Aucun document automatique.
- Aucune note automatique depuis un QCM ou un TP.

67.4 Réservations
- Capacité contrôlée pour les réservations, pas pour les inscriptions manuelles.
- Pas de transaction globale.
- Risque de dépassement en cas de confirmations simultanées.

67.5 Communications
- Pas d'email réel.
- Pas de SMS réel.
- Pas de push réel.
- Pas de notification automatique sur note, bulletin ou échéance.

67.6 Fichiers
- Pas d'upload.
- Pas de stockage de fichiers.
- Pas de PDF serveur.
- Impression via navigateur.

67.7 Comptes
- Pas de mot de passe oublié.
- Pas de changement de mot de passe dans l'interface.
- Suppression directe possible.
- Un admin peut supprimer son propre compte.
- Un compte au statut « Bloqué » ou « Inactif » peut encore se connecter dans
  l'état actuel. Pour bloquer réellement un accès, supprimez le compte ou
  intervenez dans Forge.

67.8 Suivi
- Les observations internes sont chargées côté navigateur avant masquage.
- Les réponses QCM sont présentes côté navigateur.
- Les permissions sont contrôlées côté interface.
- L'application ne filtre pas les données par formateur ou promotion.

67.9 Journal d'audit
- Toutes les actions ne sont pas tracées.
- Page en lecture seule.
- 200 lignes maximum.

67.10 Paramètres
- Les règles de notation ne sont pas utilisées par les calculs.
- Le JSON doit être valide.

67.11 Documents
- Certains types utilisent un contenu générique.
- Vérifier l'aperçu avant impression.
- Aucune unicité : plusieurs copies possibles.

69. GLOSSAIRE
--------------------------------------------------------------------------------

Affectation
Lien entre un stagiaire et un service, un formateur référent, un maître de stage
ou un groupe.

Année académique
Période de référence des promotions.

Bulletin
Document de synthèse des résultats, généré à partir de l'évaluation finale.

Capacité
Nombre maximum de places d'une promotion.

Coefficient
Valeur de pondération affichée. Dans l'état actuel, les coefficients des notes
et des modules ne sont pas appliqués aux moyennes.

Compétence
Savoir ou savoir-faire évalué par un niveau.

Évaluation
Activité notée : devoir, examen, QCM, TP, projet, etc.

Évaluation finale
Synthèse pondérée des résultats, avec une décision manuelle.

Évaluation intermédiaire
Photographie des résultats à mi-parcours.

Inscription
Lien entre un stagiaire et une formation/promotion.

Module
Partie d'une formation.

Promotion
Groupe daté d'une formation.

QCM
Questionnaire à choix multiples, corrigé automatiquement.

Réservation
Demande de place en ligne, avant confirmation administrative.

Séance
Créneau de cours planifié.

Stagiaire
Personne inscrite à une formation.

Statut
État d'un dossier, d'une inscription, d'une séance, d'une note, etc.

TP
Travail pratique avec dépôt et correction.
